# Third-Party Security Questionnaire

## Purpose

This questionnaire supports security due diligence for CloudServe Technologies prior to onboarding. Responses should be supported by appropriate evidence where applicable.

## Governance & Security Program

| Question | Vendor Response | Evidence Requested | 
|---|---|---| 
| Do you maintain a documented information security program? | Yes | Information Security Policy |
| Is security governance reviewed by senior management? | Yes | Governance documentation |
| Do you perform periodic risk assessments? | Yes | Most recent risk assessment summary |


## Access Control

| Question | Vendor Response | Evidence Requested |
|---|---|---|
| Is multi-factor authentication required for privileged access? | Yes | MFA configuration evidence |
| Are user access rights periodically reviewed? | Yes | Access review evidence |
| Is privileged access restricted and monitored? | Yes | Privileged access procedures |

## Vulnerability Management

| Question | Vendor Response | Evidence Requested |
|---|---|---|
| Are vulnerability scans performed regularly? | Yes | Recent vulnerability scan summary |
| Are critical vulnerabilities remediated within defined timelines? | No | Remediation policy and open findings |
| Are penetration tests performed periodically? | Yes | Most recent penetration test summary |

## Incident Response

| Question | Vendor Response | Evidence Requested |
|---|---|---|
| Is there a documented incident response plan? | Yes | Incident Response Plan |
| Is the incident response plan tested periodically? | Yes | Tabletop exercise evidence |
| Are customers notified following qualifying security incidents? | Yes | Incident notification procedure |

## Business Continuity

| Question | Vendor Response | Evidence Requested |
|---|---|---|
| Is there a documented business continuity and disaster recovery program? | Yes | BCP/DR documentation |
| Are recovery procedures tested periodically? | Yes | Most recent test results |
